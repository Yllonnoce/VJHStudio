# VJHStudio

(formerly RunwareStudio) — a local image and video studio for RunWare.AI

VJHStudio is a local image and video generation studio for RunWare.AI, built with FastAPI. For more information, see the specification at `.superpowers/sdd/2026-09-20-phase1-skeleton/`.

To get started, run:

```bash
uv sync && uv run vjhstudio serve
```
