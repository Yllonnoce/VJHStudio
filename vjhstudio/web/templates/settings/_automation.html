Connect an agent

Address: {{ mcp_url }} — from another computer on your network, swap {{ mcp_host }} for this computer's address.

Goose (over the network) 
extensions:
  vjhstudio:
    type: streamable_http
    name: VJHStudio
    enabled: true
    uri: "{{ mcp_url }}"
    headers: { "Authorization": "Bearer {{ mcp_masked }}" }
    timeout: 900
Claude Code (over the network) 
claude mcp add --transport http vjhstudio {{ mcp_url }} --header "Authorization: Bearer {{ mcp_masked }}"
On this computer only (stdio — no token needed)

The agent starts vjhstudio mcp itself and talks to it over its own input and output, so nothing is exposed on the network.

extensions:
  vjhstudio:
    type: stdio
    name: VJHStudio
    enabled: true
    cmd: {{ mcp_venv_bin }}/vjhstudio
    args: [mcp]
    timeout: 900

On Windows the command is {{ mcp_venv_bin_win }}\vjhstudio.exe with the same args: [mcp].
