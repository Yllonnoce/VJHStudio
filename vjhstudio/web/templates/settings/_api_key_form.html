How to get a RunWare API key
  1. Create a free account at runware.ai/signup (GitHub, Google or email).
  2. Open your dashboard at my.runware.ai and add some credit (pay as you go, in USD; unused balance does not expire).
  3. In the dashboard, open API Keys and click Create Key. Give it a name such as "VJHStudio".
  4. Copy the key right away. The dashboard only shows it in full once.
  5. Paste it below and click Save, then Test to see your balance.

The key is stored only on this computer in {{ paths.api_key_file }}. Keep it private: anyone with the key can spend your balance. You can revoke a key at any time from the API Keys page.
